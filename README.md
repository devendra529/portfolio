## 🌐 Personal Portfolio Website

A modern and responsive personal portfolio website built using Next.js to showcase projects, skills, and experience.

---

### 🚀 Features
- 👨‍💻 Showcases personal projects and technical skills  
- 📄 Dedicated sections for **About, Projects, and Contact**  
- ⚡ Fast and optimized performance using **Next.js**  
- 📱 Fully responsive design for mobile and desktop  
- 🎨 Clean and modern UI for better user experience  

---

### 🛠️ Tech Stack
- Next.js  
- JavaScript  
- HTML  
- CSS  

---
